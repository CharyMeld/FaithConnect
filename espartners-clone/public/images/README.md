# Images Directory

This directory should contain the following images for the ESPartners website clone:

## Required Images

### Logo
- `logo.png` - Main ESPartners logo (used in header)

### Hero Section
- `hero-slide-1.jpg` - First hero slider image
- `hero-slide-2.jpg` - Second hero slider image

### Solutions Section
- `insights.jpg` - Insights solution image
- `scale.jpg` - Scale solution image

### About Section
- `eric-kacou.jpg` - Photo of Eric Kacou (Co-founder)

### Data Section Icons
- `icon-job-creation.png` - Job creation icon
- `icon-women-inclusion.png` - Women inclusion icon

### Blog Section
- `blog-1.jpg` - Blog post 1 featured image
- `blog-2.jpg` - Blog post 2 featured image
- `blog-3.jpg` - Blog post 3 featured image

## Note
Currently, these image paths are referenced in the React components but the actual image files need to be added to this directory.

You can:
1. Download images from the original espartners.co website
2. Use placeholder images from services like unsplash.com or placeholder.com
3. Create custom images that match the brand aesthetic
